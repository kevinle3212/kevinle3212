### 👤 About

- 🛠️ I build across the stack — **TypeScript/Next.js** on the web, **Swift** on iOS, **Solidity** on-chain, and **Python** for ML pipelines.
- 🔐 I care about **privacy, correctness, and accessibility** — software that respects the people using it.
- 🌐 Two threads run through my work: **on-device systems that never leak your data**, and **trustless protocols that don't need a middleman**.
- 🤝 Open-source by default. I like turning hard problems into clean, auditable systems.
